# Shirokai Dex 0.7.0-dev.1 — experimental

Minecraft 1.21.1 • Fabric • Java 21 • Cobblemon 1.8.3.

Menus independentes: `/dex nacional|special|shiny|forms`, `/dexrank captura|derrotados|dex` e `/wiki nacional|special|shiny|forms`. `/dex` sozinho não abre tela. Wiki com modelos oficiais, borda de vidro, relógio para filtros, livro para pesquisa no chat e funil para limpar. Forms permanece futura; eventos desativados.

Doze arquivos editáveis em `config/shirokaidex/menus/`, criados quando ausentes. Recarregue com `/dex admin reload`. Dezoito pacotes e layout convertidos somente das configurações DexRewards: nenhum jogador ou resgate importado. Itens, dólares/tokens e permissões de tags são entregues pelo journal; moedas exigem Impactor 5.3.5/JSON nativo e moedas registradas; tags exigem LuckPerms. O Dex não instala/configura esses provedores. Placeholders de progresso e percentual usam Text Placeholder API compatível, necessária também no consumidor externo.

410 JUnit e15 verificações em servidor aprovados, incluindo captura/ranking, rejeição de origem administrativa, pacote integral, resgate único e reinício. CI exige SHA256 idêntico ao JAR validado nativamente. Não certifica cliente gráfico/carga ou uma GUI externa específica. A causa da captura não contada no servidor do responsável ainda não foi confirmada.

Instale somente o JAR em mods/, preservando backups de mundo/configurações/SQLite (schema16). As configurações antigas de apresentação/coleções/recompensas são substituídas no fluxo ativo pelos novos arquivos de menus; dados históricos são preservados. Preserve os IDs dos novos prêmios após uso. Veja DIRECT_MENUS.md no ZIP de configurações. Main e ambiente não publicados.

Anexos: JAR, direct-menu-config.zip, validation.json, BUILD_PROVENANCE.json e SHA256SUMS.
