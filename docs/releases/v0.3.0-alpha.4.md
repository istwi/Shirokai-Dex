# Shirokai Dex 0.3.0-alpha.4

**Distribuição:** código-fonte disponível nesta release. O JAR foi gerado e validado localmente, mas o upload dos anexos foi bloqueado por `HTTP 401 Bad credentials` em `uploads.github.com`. Não há JAR instalável nem SHA256SUMS anexados nesta publicação.

Pré-release experimental para servidor **Minecraft 1.21.1 / Fabric / Java 21 / Cobblemon 1.8.3**.

## Novidades

- Coleções com categorias nomeadas/versionadas e progresso percentual oficial.
- Recompensas de itens, componentes/itens salvos e Pokémon, com prévia e confirmação.
- Desbloqueios permanentes, journal SQLite e revisão de entregas incertas para evitar repetição automática.
- Central `/dex`, paletas e posições configuráveis, grade de recompensas e estilo compartilhado dos submenus.
- Exibição dos estados reais de resgate e barra de progresso sem arredondamento para conclusão prematura.

## Instalação

Quando o anexo estiver disponível, baixe o JAR `shirokai-dex-0.3.0-alpha.4+mc1.21.1-cobblemon1.8.3.jar` e coloque na pasta `mods` do servidor. Não instale o arquivo `-sources.jar`. Requer Fabric Loader >=0.17.2, Fabric API >=0.116.6+1.21.1, Fabric Language Kotlin >=1.13.6+kotlin.2.2.20 e Cobblemon 1.8.3+1.21.1. LuckPerms e Text Placeholder API são opcionais. As dependências não estão incluídas.

Antes de atualizar, faça backup da pasta de configuração e do banco SQLite com o servidor parado: há migrações de schema até a versão 5. As recompensas Pokémon exigem os stores NBT nativos do Cobblemon; JSON/Mongo/provedores personalizados não estão certificados.

## Validação e limites

Build aprovado e **218 testes JUnit sem falhas, erros ou skips**. Relatórios de testes anteriores em servidor dev estão em `docs/validation`, incluindo itens/componentes, desbloqueios, Pokémon e primeira passagem da central.

A segunda passagem dos submenus ainda requer repetição de navegação em servidor e inspeção em cliente gráfico. Instalação deste JAR fora do Loom e teste de carga não foram certificados. Esta alpha não representa o mod completo.

Moedas/Impactor, chaves Crates, COMMAND, conquistas e competições continuam pendentes. Entregas incertas exigem revisão; não existe transação atômica entre SQLite e inventário/stores externos. Use primeiro em um servidor de testes.

O JAR e SHA256SUMS permanecem gerados no ambiente local; o upload exige corrigir o acesso de autenticação ao host de anexos do GitHub.
