# Shirokai Dex v0.4.0-alpha.1 — experimental

Minecraft **1.21.1**, Fabric Loader **0.17.2+**, Java **21**, Cobblemon **1.8.3+1.21.1**, Fabric API **0.116.6+1.21.1** e Fabric Language Kotlin **1.13.6+kotlin.2.2.20**. Impactor5.3.5 e LuckPermsFabric5.4.140 são opcionais no escopo documentado; funcionalidades administrativas/econômicas dependem deles.

Baixe e instale somente `shirokai-dex-0.4.0-alpha.1+mc1.21.1-cobblemon1.8.3.jar` em `mods`. Não instalar probes/datapacks de teste. Confira `SHA256SUMS.txt`. Não é uma release estável nem o mod completo.

## Incluído

- Pokédex/progresso, coleções/categorias e wiki, com menus configuráveis no escopo já documentado.
- Recompensas de itens/componentes/Pokémon/moedas e COMMAND isolado com revisão obrigatória. Journal, prévia/confirmação e recuperação administrativa somente de operações sem etapas iniciadas; efeitos incertos não são reenviados automaticamente.
- Capturas/estatísticas iniciais: origem nativa PlayerSpawner/pool mundial, deduplicação persistente, snapshots de classificação e contadores permanentes.
- `/dex profile captures`, consultas próprias por espécie/categoria e fuso configurável.

## Validação e limites

Commit funcional **78dfe72f8cef55f20c3645dc132ea6c3d97ad6f0**. **304 testes JUnit** e **18 verificações locais em servidor empacotado**, incluindo capturas positivas pelo motor real, caso administrativo não contado, replay, migração5→6 e regressão de recuperação/reinícios. O build de publicação repete os 304 JUnit; o relatório nativo conserva o hash do binário local testado, separado do hash do JAR construído no CI. Proveniência explicita se esses hashes coincidem.

**Limite importante:** SpawnCause foi perdido após recarregar a entidade no teste; sua captura ficou UNKNOWN e não aumentou totais legítimos. Batalha/pesca/outros spawners, proveniência contínua, Shiny% ligada ao ledger, histórico/admin/recordes e competições/rankings ainda não estão concluídos. Não presume capturas anteriores à instalação, origem válida sem prova ou transação distribuída com inventário/APIs externas.

**Banco schema6:** faça backup antes de atualizar um servidor real. Migração preserva planos anteriores no escopo testado. Não abra o banco migrado com JAR antigo que só suporta schema5. Cliente visual, carga, qualquer modpack e recuperação após perda de energia não são certificados.

A tag desta pré-release é fixada no commit funcional acima, sem integrar a branch de desenvolvimento à main. Releases anteriores permanecem intactas. Nenhuma configuração de ambiente publicada.
