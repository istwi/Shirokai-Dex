# Shirokai Dex 0.6.0-dev.1 — experimental

Snapshot de desenvolvimento para Minecraft 1.21.1, Fabric 0.17.2, Java21 e Cobblemon1.8.3. Não é o mod concluído.

Inclui histórico/retenção, rankings/recordes, competições e prêmios, perfis/privacidade e conquistas. Build e 382 testes JUnit aprovados; evidências nativas de fases4/5 incluídas no repositório. A suíte nativa de perfis está em validação: consulte o relatório anexado para o resultado exato.

Pendentes: placeholders avançados e integrações opcionais, menus JSON das novas telas, notificações, recálculo administrativo de categorias, desempenho e validação gráfica/final. CRATE_KEY dedicado não certificado.

Faça backup do mundo, configuração e banco antes de instalar: schema14 com migrações; não faça downgrade sem restaurar backup. Instale apenas o JAR de produção em mods/, com as dependências exigidas. Confira SHA256SUMS antes de usar.
